## 1. 技术栈总览

### 前端框架
- **纯原生 JavaScript (Vanilla JS)** - 未使用 React/Vue 等框架
- **Chrome Extension Manifest V3**
- **Chrome Storage API** - 持久化配置存储
- **DOM 操作** - 直接操作页面DOM元素

### AI 接口调用
- **OpenAI 兼容 API 格式**
- 支持任何 OpenAI 兼容的端点（用户自定义配置）
- 模型：用户可配置（如 GPT-4、Claude、Haiku 等）
- 调用方式：原生 `fetch()` API

### 知识库实现方式
- **简单文本注入** - 没有向量数据库或复杂检索
- 整个知识库内容直接附加到 System Prompt 中
- 格式：`---\n[Knowledge Base]\n{知识库内容}`

### 与社媒平台交互方式
- **Content Script DOM 操作**
- 通过 `window.getSelection()` 获取用户选中的评论文本
- 通过 `navigator.clipboard` 实现复制功能

```javascript
// 获取平台 Prompt（支持复用逻辑）
function getPlatformPrompt(config, platformId) {
  // 支持跨平台复用，递归查找
  const visited = new Set();  // 防止循环引用

  function getPrompt(id) {
    if (visited.has(id)) {
      return DEFAULT_PROMPT;  // 循环引用保护
    }
    visited.add(id);

    const platform = config.platforms[id];
    if (!platform) return DEFAULT_PROMPT;

    // 如果配置了复用
    if (platform.promptReuse) {
      return getPrompt(platform.promptReuse);  // 递归获取
    }

    return platform.prompt || DEFAULT_PROMPT;
  }

  return getPrompt(platformId);
}
```

### 3.5 响应数据处理和展示

**位置**: [content.js:968-1033](meta-reply-assistant%206.0/content.js#L968-L1033)

```javascript
// 解析三段式回复（小语种）
function parseMultilingualResponse(content) {
  const result = { commentTranslation: '', reply: '', replyTranslation: '' };

  // 支持中英文标签
  const commentMatch = content.match(/\[Comment Translation\](.+?)(?=\[|$)/s);
  const replyMatch = content.match(/\[Reply\](.+?)(?=\[|$)/s);
  const replyTransMatch = content.match(/\[Reply Translation\](.+?)(?=\[|$)/s);

  if (commentMatch) result.commentTranslation = commentMatch[1].trim();
  if (replyMatch) result.reply = replyMatch[1].trim();
  if (replyTransMatch) result.replyTranslation = replyTransMatch[1].trim();

  return result;
}

// 渲染结果
function renderResult(resultArea, aiResponse) {
  const hasTranslationFormat = aiResponse.content.includes('[Comment Translation]');

  if (!hasTranslationFormat) {
    // 英文/中文：直接显示回复
    resultArea.innerHTML = `<div class="section-box">${aiResponse.content}</div>`;
  } else {
    // 小语种：显示三段式
    const parsed = parseMultilingualResponse(aiResponse.content);
    resultArea.innerHTML = `
      <div class="translation-block">
        <div class="translation-label">📖 Comment Translation</div>
        <div class="translation-content">${parsed.commentTranslation}</div>
      </div>
      <div class="translation-block">
        <div class="translation-label">💬 Reply</div>
        <div class="translation-content">${parsed.reply}</div>
      </div>
      <div class="translation-block">
        <div class="translation-label">🔤 Reply Translation</div>
        <div class="translation-content">${parsed.replyTranslation}</div>
      </div>`;
  }
}
```

## 4. 当前痛点定位

### 4.1 响应慢（尤其小语种）

**可能原因分析**:

1. **模型选择问题**
   - 使用用户配置的模型，可能是较慢的模型（如 GPT-4）
   - 未针对小语种使用更快的模型（如 Haiku）

2. **Prompt 过长**
   - 知识库整个注入上下文，可能占用大量 token
   - 小语种模式下要求 AI 输出三段式内容，生成耗时更长

3. **API 调用方式**
   - 每次请求都是同步调用，无并发优化
   - 使用了故障切换机制，但单次调用仍是串行

**代码证据**:
- [content.js:864-866](meta-reply-assistant%206.0/content.js#L864-L866) - 知识库完整注入
- [content.js:871-883](meta-reply-assistant%206.0/content.js#L871-L883) - 小语种三段式要求

---

### 4.2 翻译失败

**可能原因分析**:

1. **Prompt 没有区分翻译和润色**
   - 当前翻译 Prompt 明确是"翻译+润色"组合任务
   - 如果用户只是想翻译，可能导致 AI 输出不符合预期

2. **参数传递问题**
   - 翻译模式下没有特别指定输出语言
   - AI 需要自己"匹配原始评论的语言"，可能判断错误

**代码证据**:
- [content.js:54-66](meta-reply-assistant%206.0/content.js#L54-L66) - 翻译 Prompt 包含"Translate AND polish"
- [content.js:62](meta-reply-assistant%206.0/content.js#L62) - "Match the language of the original comment"

---

### 4.3 回复质量差

**可能原因分析**:

1. **知识库使用方式**
   - 没有检索机制，整个知识库塞给 AI
   - 如果知识库很长，AI 可能"注意力分散"，抓不住重点

2. **注入方式问题**
   - 知识库直接附加在 System Prompt 后面
   - 没有强调知识库的重要性或使用方式

3. **默认 Prompt 过于简单**
   - 平台默认 Prompt 只有 5 行，指导不够具体

**代码证据**:
- [content.js:864-866](meta-reply-assistant%206.0/content.js#L864-L866) - 简单拼接知识库
- [content.js:44-51](meta-reply-assistant%206.0/content.js#L44-L51) - 默认 Prompt 简短

```javascript
function isEnglish(text) {
  const englishChars = text.match(/[a-zA-Z]/g) || [];
  const totalChars = text.replace(/\s/g, '').length;
  return totalChars > 0 && (englishChars.length / totalChars) > 0.7;
}

function isChinese(text) {
  const chineseChars = text.match(/[\u4e00-\u9fff\u3400-\u4dbf]/g) || [];
  const totalChars = text.replace(/\s/g, '').length;
  return totalChars > 0 && (chineseChars.length / totalChars) > 0.3;
}
```
